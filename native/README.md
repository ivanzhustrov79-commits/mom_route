# Нативная оболочка

Зачем она: iOS не даёт закрытому веб-приложению никаких таймеров, поэтому
напоминания и не приходили. Локальные уведомления планирует сама система —
они срабатывают при закрытом приложении, без сервера и без ключей.

Интерфейс при этом остаётся тем же: `server.url` смотрит на GitHub Pages,
так что правки экрана доезжают без пересборки. Пересобирать нужно только
саму оболочку — то есть почти никогда.

## Иконка

`native/icon-1024.png` уже лежит рядом. Проще всего:

```
npx @capacitor/assets generate --iconBackgroundColor '#0b0b0b' --ios
```

Либо вручную: в Xcode открыть `App/Assets.xcassets/AppIcon` и перетащить
файл в ячейку 1024×1024.

## Сборка на Mac

```
cd native
npm install
npx cap add ios
npx cap sync ios
npx cap open ios
```

Откроется Xcode. Дальше:

1. Слева выбрать проект **App** → вкладка **Signing & Capabilities**.
2. **Team**: свой Apple ID (Xcode → Settings → Accounts → «+»). Личная
   команда бесплатна.
3. **Bundle Identifier** сделать своим: `com.<фамилия>.momroute`.
4. Подключить айфон кабелем, выбрать его сверху, нажать ▶.
5. На телефоне: Настройки → Основные → VPN и управление устройством →
   доверять своему сертификату.

## Про бесплатную подпись

Бесплатный сертификат живёт **7 дней**: через неделю приложение перестаёт
запускаться, надо снова нажать ▶ в Xcode. Локальные уведомления при этом
работают полностью — платный аккаунт нужен для пуш-уведомлений, а они нам
не нужны.

Программа разработчика ($99/год) даёт год вместо недели и TestFlight, то
есть установку жене по ссылке, без кабеля.
