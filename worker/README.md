# Будильник для «Маршрута»

Воркер не знает ни имён, ни адресов. Телефон присылает список моментов
времени, воркер в нужную минуту шлёт пуш **без содержимого**, а текст
уведомления телефон достаёт из своей же локальной базы.

## Развёртывание

```
node tools/vapid.js                 # из корня проекта — выдаст пару ключей
cd worker
npx wrangler login                  # вход через браузер, токен не нужен
npx wrangler kv namespace create PUSHQ
```

Полученный `id` вписать в `wrangler.toml`, туда же — **открытый** ключ.
Затем два секрета (они хранятся у Cloudflare в зашифрованном виде и в
репозиторий не попадают):

```
npx wrangler secret put VAPID_PRIVATE   # JSON закрытого ключа одной строкой
npx wrangler secret put APP_SECRET      # любая длинная строка
npx wrangler deploy
```

Адрес вида `https://momroute-push.<аккаунт>.workers.dev` и тот же
`APP_SECRET` вписать в приложении: Настройки → Уведомления.

## Где что лежит

| | Где | Секрет? |
|---|---|---|
| Открытый ключ VAPID | `js/push.js` и `wrangler.toml` | нет, он публичный по устройству |
| Закрытый ключ VAPID | секрет Cloudflare | **да** |
| Общий пароль | секрет Cloudflare + localStorage телефона | **да** |
| Токен Cloudflare | не нужен, `wrangler login` | — |

## Бесплатный тариф

100 000 запросов в день и cron-триггеры входят в бесплатный план. Одна
семья расходует порядка полутора тысяч срабатываний в сутки — это минута
за минутой, вне зависимости от числа уведомлений.
